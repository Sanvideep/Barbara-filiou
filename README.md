# Barbara Filiou — Olympic Gymnast & Elite Coach Portfolio

Official booking and portfolio website for **Barbara (Varvara) Filiou**, Olympic Rhythmic Gymnast (Rio 2016), World & European Finalist, and 13-time Greek National Champion.

## 🌟 Features

- **Full-Screen Hero Showcase**: High-resolution Olympic editorial card with handwritten typography and direct booking CTA.
- **Vintage Manuscript Aesthetic**: Custom antique parchment textures, deckled borders, and gold-embossed accents throughout.
- **Interactive Booking Dispatch**: Airmail envelope sliding letter experience with form submission for Masterclasses, Training Camps, and Elite Choreography.
- **Client Reviews Archive**: Continuous vertical reviews feed mounted on rough aged parchment paper with washi tape details.
- **Worldwide Masterclasses Dossier**: Global track record gallery and statistics counter across 5 continents.
- **Responsive & Modern Architecture**: Built with React, TypeScript, Vite, Tailwind CSS, Lucide Icons, and Vanilla CSS animations.

## 🚀 Quick Start

### Prerequisites
- Node.js (v18+)
- pnpm (or npm / yarn)

### Installation & Running Locally

```bash
# Install dependencies
pnpm install

# Start the development server
pnpm run dev
```

The site will be running at `http://localhost:3000`.

### Production Build

```bash
pnpm run build
```
